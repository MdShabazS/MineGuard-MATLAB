# V22-T10 — Honest evaluation and IMAS wording (owner: Shabaz) · BUILD

**Why:** research report `v2_2/research/V22_RESEARCH_DRONE_LANDMINE_SURVEY.md`, recommendations 1–2:
- IMAS 07.11: indirect evidence only creates a *suspected* hazardous area, and decisions rest on evidence, not its absence.
- Detection is binomial and should be reported with exact intervals.

## Inputs

- The research report and notes `v2_2/research/notes/safety_ethics_simulation.md`.
- V2.1 run evidence: `v2_1/evidence/V21-008/v21_demo_check_*.txt` (TP, FP, FN per run) and `v2_1/evidence/V21-008.md`.
- `mgv21.evaluation.evaluateRun` (the R struct: events, matched indices).

## Steps (subagents: one for statistics and tests, one for the wording sweep and doc)

1. **Statistics:** `v2_2/matlab/+mgv22/+evaluation/`:
   - `clopperPearson(k, n, conf)`: exact two-sided interval, base MATLAB (`betaincinv`). For k = 0: lower 0, upper `1 - (alpha/2)^(1/n)`.
   - `falseAlarmRate(fp, area_m2, conf)`: false alarms per hectare with a Poisson interval (`gammaincinv`).
   - `detectionCurve(scores, isTP, nTargets)`: detection rate vs false alarms per hectare as the score threshold sweeps. Use the event score field.
2. **Bounded null result:** from the recorded V2.1 runs: 0 of 13 targets (count from the logs; earlier summaries said 12). Compute the interval in MATLAB (upper bound 24.7 %), plus false alarms per hectare per run and overall, using each run's field area.
3. **Wording:** `+mgv22/wording.m` returns the standard strings:
   - `SIMULATION – suspected anomaly, indirect evidence only`;
   - `No detection here does not mean safe`;
   - the list of forbidden words for result text: "clear", "cleared", "safe", "mine found".

   Use it in the v2_2 views' result text. Do not change V2 or V2.1 code; note any V2.1 text for V22-T6.
4. **Doc:** `v2_2/docs/V22_T10_EVALUATION_AND_WORDING.md`:
   - the bounded result table;
   - false alarms per hectare;
   - what the interval means;
   - the wording rule with its IMAS source;
   - the **sealed virtual test area design**: a held-out synthetic site with clutter (rocks, scrap, disturbed soil), fixed target count and mix, metrics registered before running, run once, report detection and false-alarm rates with intervals, and no retuning on it.

## Tests: `v2_2/tests/testV22Evaluation.m`

- The Clopper-Pearson interval matches known values: k=0, n=12 gives an upper bound of 0.2646; k=n; k=5, n=10 against a reference.
- Coverage: the bounds bracket the observed proportion.
- Poisson false-alarm interval for 0 and many false alarms.
- `detectionCurve` is monotone.
- The wording helper has no forbidden word in its positive strings.
- No v2_2 view result text contains a forbidden word.
