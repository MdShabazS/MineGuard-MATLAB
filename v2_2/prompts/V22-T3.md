## Steps

1. **Exact credit text:** in MATLAB (desktop), open a `geoaxes` with `geobasemap(g,'satellite')`, read the attribution text MATLAB shows, and copy it exactly. Do not save a screenshot to the repository.
2. **Decision document:** write `v2_2/docs/V22_T3_MAP_SOURCE_AND_LOCATION.md`:
   - **Source:** MATLAB `geobasemap('satellite')`, online Esri World Imagery, live display only.
   - **Credit text:** exactly as shown on screen.
   - **Allowed:** live display with credits in demos; code in the repository.
   - **Not allowed** unless written permission is recorded: committing map tiles, cached imagery or screenshots of imagery to the public repository; offline tile caching for the demo.
   - **Offline fallback:** ENH-009 schematic (`v2/enhancements/+mgenh009`).
   - **BITM anchor and view window:** values with sources and confidence. State that this is a presentation anchor, not a survey point, and that the mission route is VIRTUAL.
3. **Confirmation:** show Danish the anchor and window in one short message and ask him to confirm them. Record "confirmed by Danish on <date>" or his corrected values.
4. **Site file:** write `v2_2/config/bitm_site.json`:
   ```json
   {"schema":"mg-v22-site/1.0","anchor_lla":[lat,lon,0],"view_window":{"lat":[min,max],"lon":[min,max]},
    "basemap":"satellite","credit_text":"…","banner":"REAL IMAGERY — SIMULATED FLIGHT / NOT A HAZARD MAP",
    "offline_fallback":"mgenh009.renderOfflineCampusContext","commit_imagery_allowed":false,"sources":["…"]}
   ```
   Altitude 0 means no approved altitude; T4 must not treat it as a survey height.
5. **Check the file parses:** `node -e "JSON.parse(require('fs').readFileSync('v2_2/config/bitm_site.json'))"`.
