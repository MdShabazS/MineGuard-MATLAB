# Ethics, Safety, Public GitHub and Publication Rules

## Scope and risk communication
MineGuard is an **educational simulation of suspected anomaly surveying**. A simulated output cannot validate mine clearance, confirm an explosive device, declare an area safe or justify entering a hazardous area. No operational field guidance will be provided.

## Public repo inventory
**Allowed:** code, reproducible synthetic scenarios, model assumptions, test logs with personal information removed, Markdown research and publicly licensable small fixtures.
**Never commit:** MATLAB product keys/licence IDs, API credentials, Claude OAuth/session tokens, student identity documents, passwords, secrets, private hardware coordinates, third-party restricted images or hidden-field operational data.
**Check:** GitHub diff before PR, .gitignore patterns, security scanners, any rendered screenshot for licence popups/student names.

## MathWorks legal constraints
Install MATLAB and toolboxes through authorised student/college entitlements. The MATLAB Agentic Toolkit's MCP Server is used under MathWorks Software License Agreement and is **not** a shared MATLAB service for multiple users. Each tester's MATLAB activation and product entitlements are independent. Do not publish compiler runtimes or commercial binaries without checking licensing terms.
Reference: https://github.com/matlab/matlab-agentic-toolkit

## AI agent governance
- Claude Code and ChatGPT can research, author and test only with actual accessible tools; they must not hallucinate execution.
- Require review of proposed file edits, tool commands and public communication.
- AI-generated report passages must be checked for fabricated bibliography and numeric claims.
- Keep one actual human reviewer independent of PR author; release remains a human decision.
- Avoid malicious script execution copied from unreviewed websites.

## Data and scientific ethics
- Separate synthetic labels from observations and inference, and disclose the domain gap.
- Public scientific literature figures are not ours; state study authors and settings.
- Use licensed and attributed datasets; do not upload Mendeley/Elsevier image content without rights.
- Don't present an algorithm confidence score as calibrated probability of an explosive object in real terrain.

## Guide portal
Read-only progress display based on public GitHub. No guide authentication, internal unpublished project details or proprietary API key. The guide is not subscribed automatically to active notifications; he checks a link. Confirm what the portal makes public is acceptable to the college.
