# Immutable Phase-1 Problem Statement and Objectives

**Source:** `Review1Phase1.pptx` (Review-1 of Project Phase-1, slides 3–4), supplied previously by the team. Preserve exact words; spacing/line wrapping normalized only.

## Title
MineGuard — Autonomous Aerial Landmine Detection System

## Objectives — EXACT ORIGINAL WORDING
1. To design and develop an autonomous drone system that scans suspected landmine fields by following a pre-programmed flight path without manual intervention.
2. To detect subsurface landmines accurately by integrating a metal detector coil and thermal camera with a sensor fusion algorithm that minimizes false detections.
3. To geo-tag and map every detected threat using a GPS module and display real-time detection data on a ground control station dashboard accessible from a safe distance.
4. To eliminate human exposure during landmine survey operations by replacing dangerous manual ground sweeping with a fully autonomous aerial detection system.

## Problem Statement — EXACT ORIGINAL WORDING
- Landmines in post-conflict areas pose a serious threat to human life and restrict land usage.
- Manual detection methods are slow, costly, and highly dangerous for personnel.
- Existing systems still require human presence in hazardous zones.
- There is a need for a safe, fast, and accurate detection system.
- An autonomous drone-based solution can detect, geo-tag, and map landmines without human risk.

## 2026-10-31 Implementation Change (not an objective revision)
Guide directed a **MATLAB-based advanced simulation** instead of ₹1 lakh+ physical sensor/drone integration. The academic title/problem/objectives above stay unchanged. Demonstrations may validate **virtual** navigation, **simulated** subsurface responses, virtual GPS and dashboard operation. Neither a simulation nor its scores establish an aircraft can detect buried mines at realistic standoff distances. Any field-feasibility limitation is to be disclosed explicitly, not edited out of the original objectives.

Every report and presentation must (a) reproduce this exact baseline and (b) distinguish intended objectives, simulated achievement, and unvalidated real-world claims.
