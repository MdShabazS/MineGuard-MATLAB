What it does:
- Choose one of three presets.
- Edit a rectangle or polygon boundary, the home position, line spacing, heading, altitude and speed.
- See the generated route, or the validation error instead of a route.
- Choose NONE, MANUAL or RANDOM placement:
  - MANUAL: add, move or delete targets by clicking the map; each click is checked with `checkLocation`.
  - RANDOM: set the count and seed.
- LOCK & START removes every marker and disables editing, then hands `(pub, world, priv)` to the runtime exactly once. The spec and `priv` are private.

UI decisions where the contract is silent:
- the world is cached per `scene_config`;
- RANDOM spec fields are written directly and checked by `lockScenario`;
- MANUAL burial depth defaults to 0.1 m;
- a target being moved is excluded from its own spacing check;
- changing the preset resets the spec.
