Task: V21-007

Design:
- **Version:** a V2.1 run exports as `mg-v2-runpkg/1.1`, a compatible extension. It adds `config.scene_config` and `manifest.private_forward_model = {used, features_sha256}`, a SHA-256 commitment that does not reveal positions.
- **V2 compatibility:** a default V2 run still exports `mg-v2-runpkg/1.0` with no new field. `verifyPackage` accepts both.
- **Replay:** uses recorded data only, and is refused in a different world (`world_digest`).
- **Reproduce:** a 1.1 run can be re-simulated only with the same private features (`mgv2:PrivateScenarioRequired` otherwise).
- **Private evaluation file** (decision under contract §5):
  - `RunController.savePrivateEvaluation(folder)` writes `<run>_g<gen>_PRIVATE_EVALUATION.mat`, only on request.
  - It is never written inside an operator package, and never overwritten.
  - It holds the evaluation, the truth, `pub` and the feature commitment that links it to the package.

## Fix F1: salted commitment (found by Shabaz's Mac review, #132)

The first design stored an **unsalted** SHA-256 of the private features. That hash contains no positions, but for a RANDOM layout with a guessable seed, someone with the code could regenerate candidate layouts and confirm one against the package. The earlier wording "does not reveal positions" was therefore too strong.

The fix:
- `manifest.private_forward_model.features_sha256` is now `mgv2.ui.MissionSession.commit(F, salt)`: `mgv2.run.digest` over `{salt, features}`.
- The salt is 128 random bits from Java `SecureRandom`, made by `RunController` and held privately.
- The salt is written only to the private evaluation file, together with the features, so reproduction stays possible. It is never written to the package.
- `mgv2.run.reproduce` needs `SurfaceFeatures` and `CommitmentSalt`.

Tests:
- the unsalted hash does not match the package;
- the salt is in no package text file;
- each session gets a fresh salt;
- reproduction fails with no salt or a wrong salt;
- reproduction succeeds from the private file's contents.
