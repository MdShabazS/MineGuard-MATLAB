## 1. Summary

- **What it is:** `mgv2.engine.MissionEngine` is a deterministic, fixed-step, headless MATLAB engine. It runs a complete virtual mission: CONFIGURED → PREFLIGHT → TAKEOFF → CLIMB → TRANSIT → SURVEY → RETURN_HOME → LANDING → COMPLETE.
- **Faults are explicit terminal states:** FAILED (`PREFLIGHT_TERRAIN`, `PREFLIGHT_UNREACHABLE`, `CLEARANCE`, `TERRAIN_COLLISION`, `GEOFENCE`, `TIMEOUT`) and ABORTED (`ABORTED_BY_OPERATOR`).
- **Real progression:** the mission progresses only as `step()` is called. Every tick integrates the vehicle state from the guidance output; there is no precomputed trajectory playback.
- **COMPLETE requires touchdown** at home. A mission stopped early is never COMPLETE (test t08).
- **Research and decisions** are in [`v2/docs/V2_002_003_ENGINEERING_DECISIONS.md`](../docs/V2_002_003_ENGINEERING_DECISIONS.md). That covers the compared approaches, the verified R2026b API facts, the measured renderer spike, the rejected alternatives, risks and the verified references.

## 2. Architecture (as implemented)

```text
MissionConfig (mg-v2-contract/1.0 subset, exact allowlist) --validateConfig--> MissionEngine
   +-- SimulationClock: integer tick_id, t_s = tick_id*dt (dt 0.05 s); never reads the wall clock
   +-- planSurvey: convex boustrophedon lines at any heading (centred, alternating)
   +-- buildRoute: one continuous TRANSIT->SURVEY->RETURN_HOME path + documented home corridors
   +-- guidance: L1-style look-ahead carrot, corner/braking speed profile, terrain following at AGL
   +-- vehicle model: bounded accel/tilt, 0.15 s thrust lag, drag on airspeed, seeded wind/gusts,
   |                  differential-flatness attitude, rate-limited yaw
   +-- safety: clearance, terrain collision, geofence + corridors, timeout, preflight feasibility
   +-- outputs: snapshot() PoseSample per tick, poseLog() table, PhaseLog, subscribe(fcn)
Terrain provider (struct: id, heightAt(x,y)) — heights only, never hidden target truth.
```

The engine has no graphics dependency. The V2-003 renderer consumes PoseSamples; it never drives the clock. The UAV Toolbox boundary is the single adapter `mgv2.frames.poseEnuToNed/poseNedToEnu`.

### PoseSample fields (per tick, `schema_version "mg-v2-contract/1.0"`, `record_type "PoseSample"`)

- **Identity and time:** `run_id`, `scenario_id`, `seed`, `pose_id`, `tick_id`, `t_s`
- **Motion:** `position_enu_m`, `velocity_enu_mps`, `acceleration_enu_mps2`
- **Attitude:**
  - `orientation_quat` ([w x y z], body FLU → world ENU), with `quat_convention` stating this
  - `angular_velocity_body_rps`, `yaw_rad`, `heading_deg` (compass)
  - `pitch_up_rad`, `roll_right_down_rad`
- **Height:** `altitude_agl_m`, `terrain_height_m`
- **Commanded vs actual:** `commanded_position_enu_m`, `wind_enu_mps`
- **State and flags:** `phase`, `validity`, `fault_code`, `simulated = true`

## 7. Known limitations and outstanding issues

1. **macOS: verified for combined tests and live 3-D mission on 2026-11-01; stand-alone 2-D monitor tests are not separately evidenced on Mac.** The following commands remain available for regression:
   ```matlab
   cd <repo>; addpath('v2/matlab');
   r = runtests('v2/matlab/tests/testV2002MissionEngine.m'); table(r)
   mgv2MissionDemo                  % live 2-D monitor
   mgv2MissionDemo('RealTime', 1)   % 1x pacing; report the printed sim/wall ratio
   ```
   Then record the output in this file or in V2-008.
2. **Approximate model:** the parameters (drag 0.25 1/s, τ 0.15 s, gains, limits) are documented assumptions, not identified from a real airframe. It is not a PX4/ArduPilot controller.
3. **No automatic failsafe:** after a fault the state freezes; there is no return-to-launch on failure.
4. Only convex survey polygons are supported.
5. **Terrain-following look-ahead is 2 s.** A cliff steeper than the climb rate collides, and the engine then fails explicitly.
6. **No battery model yet.** The V2-007 display will add one as a clearly labelled simulated estimate.
7. The cross-track error under the demo wind reaches 3.55 m at turns. That is expected behaviour of the approximate controller, not a tuned autopilot.
