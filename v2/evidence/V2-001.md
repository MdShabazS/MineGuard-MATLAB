- Thermal outputs in V1 are synthetic scalar response values, not real thermal images. EM is a normalized proxy, not an actual validated metal coil. V2 proposes real numeric *synthetic* thermal frame rasters but has not yet built them.
- V1 code, original scientific evidence, train/test split, run lock and V1 portal status are **not modified by V2-001**.
- Physical drone flight and GCS capability are reported by the user; Raspberry Pi and planned sensors are not yet integrated. None are required for V2 Stage 1.
- High-fidelity native MATLAB UAV visuals **do not imply photorealistic Unreal Engine support on Mac**.
- No measured V2 RGB/thermal/LiDAR frame rate, flight dynamics, map correctness, runtime FPS, FPR/recall improvement or MATLAB test PASS is claimed by this evidence file.
