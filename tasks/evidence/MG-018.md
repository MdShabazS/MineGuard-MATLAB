## 5. Open limitations — explicit, not hidden

- **Critical scientific failure:** preregistered weighted detector missed four of four positive assessable cells. OR recall = 1 only with 439 false-positive cells. No reliable buried-mine detector has been demonstrated.
- **Assumptions:** thermal/EM are uncalibrated mathematical proxies; the 5 m EM channel is out of domain; only four positive cells in the common assessed TEST population.
- **Sealed TEST:** consumed once, must remain frozen; any new threshold/scientific claim requires **fresh preregistration and a new holdout**.
- **PPO:** trained and genuinely inferred, but underperformed the fixed grid; limited to 5×5/25 actions, and comparison on eight matched feasible cases, not all twenty.
- **Flight realism:** route is a kinematic grid with ideal turns; no vehicle dynamics, collision safety or real autopilot closed loop.
- **UI:** actual desktop dashboard is a **2-D offline replay**; advanced 3-D digital twin and physical real-time GCS are not implemented.
- **Hardware:** no verified flight controller/Pi/camera/metal coil/GPS/LiDAR connection or physical safety validation.
- **Verification:** Windows 11/R2026b owner MATLAB regression logged; full macOS/Linux release test matrix is not committed. GitHub CI does not run MATLAB.
- **Provenance:** MG-019 original batch was run on a staged working tree later committed identically; its old run IDs lacked a dirty-tree marker.
- **Release:** no academic-guide approval is implied; the proposed RC tag remains uncreated until specifically authorized.

These gaps are important content for a scientific viva, not work quietly marked completed.
