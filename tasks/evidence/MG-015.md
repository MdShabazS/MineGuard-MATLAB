## Architecture (as implemented; existing modules reused unchanged unless noted)
```
config (ExperimentConfig + sensor_settings + detector_settings + run_options)
  -> mineguard.runExperiment(config)                                     [NEW, frozen MG-003 API]
     -> mineguard.evaluation.runTrial                                    [MG-009 orchestrator]
          MG-004 generateScenario -> MG-005 makeGridRoute/simulatePose/computeCoverage
          -> MG-007 simulateThermal (K) / simulateEM (dimensionless)
     -> MG-009 detectAnomalies(detectorConfig, poses, samples, frozen model)   [observables only]
     -> MG-009 evaluableCellMask (no truth) + checkProvenance
     -> MG-009 scoreDetections(config, events, truth, runMetadata)            [ONLY truth consumer]
     -> truth dropped -> MG-011 makeRunBundle (allowlisted) -> runBundle
  -> mineguard.app.openMissionApp(runBundle)                             [MG-011 desktop replay/export]
```
