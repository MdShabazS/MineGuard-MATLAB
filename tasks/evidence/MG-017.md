## 6. Known limitations and remaining risks
- **Scientific:**
  - Negative held-out detection.
  - Assumed and uncalibrated sensor proxies; a small synthetic population; the TEST is consumed.
  - Any improvement needs a new preregistered study with fresh held-out families.
- **PPO:** 5×5/25-action only; lost to the grid; not evaluated on the 10×10 GF families.
- **Platform:** Windows 11 / R2026b only. The dashboard and the UI tests need a desktop display.
- **Provenance:** `runSurveyMission` (MG-019) does not mark dirty trees; `runExperiment` does.
- **Display:** the S0 metadata still shows "split: test" (frozen MG-009 family label). It is now accompanied by the explicit display-fixture line.
- **Not implemented:** 3-D replay, live GCS, real GNSS or sensors, hardware integration, physical flight.
- **Risk:** someone could present S0 or coverage figures as detection accuracy. Mitigation: console, dashboard, README and release notes all state the negative held-out result next to them.
